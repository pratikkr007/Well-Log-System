Well Log Analysis System
📌 Project Overview

This project is a web-based Well Log Analysis System built using:

Backend: FastAPI

Database: PostgreSQL

Frontend: React (Vite) + Tailwind CSS v4

AI Integration: Google Gemini API

Visualization: Plotly

The system allows:

LAS file upload

Curve visualization

Statistical analysis

AI interpretation

Chatbot-based Q&A over selected well data
